## 🆘 TROUBLESHOOTING

### GitHub Actions Not Running?
- Check Actions tab in repository
- Verify workflow file syntax
- Check branch protection rules
- Look for error messages in logs

### Badges Not Displaying?
- Verify URL format
- Check internet connectivity
- Wait a few minutes (cache)
- Test in incognito window

### Profile Stats Not Updating?
- Check that repository is public
- Verify username is correct
- Wait for refresh (can take 24h)
- Check komarev service status

### Commits Not Showing?
- Ensure git email matches GitHub email
- Verify commits are to default branch
- Check commit timestamp
- Review contribution settings
